## Late Session Fixes (post-EOD)

### Alert Spam Root Cause (commits 26-27)
Proposals spammed 6 alerts every 2 minutes for hours. Chain of failures:
1. Enrichment stuck at 60% (missing LLM review, agent reviews, backtest, technicals)
2. `approval_allowed` stayed NULL → ATM deferred as "not_yet_enriched"
3. ATM gate rejections (max_new_per_day, same_day_skip) logged decision but **never updated proposal status** — proposals stayed PENDING
4. ATM `_count_new_today` counted ALL paper_trades including closed/phantom, inflating count from 1 → 3 and blocking all approvals
5. Alert cron never tracked `last_alert_at` — no dedup possible
6. Health agent didn't monitor proposal lifecycle

### Fixes Applied
| Fix | File | What |
|---|---|---|
| ATM gate rejections update status | `atm_auto_approver.py` | Rejected proposals now SET status='REJECTED' instead of just logging |
| same_day_skip rejects | `atm_auto_approver.py` | Changed from deferred→rejected (ATM will never approve these) |
| _count_new_today excludes closed | `atm_auto_approver.py` | Only counts open/pending trades, not closed/phantom |
| Blocked proposals auto-reject >30min | `send_telegram_proposal_alert.py` | Alert loop rejects BLOCKED proposals after 30 min |
| Alert dedup via last_alert_at | `send_telegram_proposal_alert.py` | Updates last_alert_at after each send, skips if <30 min |
| Proposal lifecycle cleanup | `system_health_agent.py` | Auto-rejects stuck enrichment >2h, stale >4h |
