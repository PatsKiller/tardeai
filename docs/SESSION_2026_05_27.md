## Self-Healing System (New)

### 3-Tier Architecture
| Tier | Intelligence | Frequency | What it does |
|---|---|---|---|
| **1. Python thresholds** | No LLM — rules | Every 5 min | 26 component monitors, retry_cmd, auto-expire, auto-queue |
| **2. Claude Code** | Full reasoning | Every 15 min (when needed) | Reads escalation file, diagnoses root cause, fixes code |
| **3. Local LLM review** | Pattern recognition | Nightly 8:30 PM | qwen3:14b grades health A-F, detects patterns, forecasts risks |

### Escalation Chain
1. Component stale → retry_cmd (max 2/day)
2. Retry exhausted → Telegram alert + escalation file
3. Every 15 min → Claude Code reads queue, investigates, fixes
4. Results logged to claude_interventions table
5. Command Center shows intervention log
6. Nightly → LLM reviews all errors, grades health, forecasts risks
