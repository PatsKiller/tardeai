## 15 — 1-hop same-sector held neighbours (cap 5)

The edge is the weakest honest one available: two names are neighbours when the
**existing** `holdings.resolved_sector_contributors` map puts them in the same
sector. Nothing new is fetched or inferred; a missing sector map returns
`DATA_UNAVAILABLE` rather than an empty success.

Ranking is deterministic — shared-sector count, then the neighbour's summed
contribution across those shared sectors, then alphabetical — so the same book
always produces the same five names.

Dust is excluded on **both** sides: a residual share has no neighbours and is
never listed as one.

## 17 — `identity_lookup_failed` ≠ `UNRESOLVED`

`lookup_subject` previously returned one identical "empty" record for four
different situations, so **a registry that could not be read was indistinguishable
from a registry that answered "no such entity."** An outage read as a clean
negative.

`identity_lookup` now separates them; `identity_status` keeps its old contract,
so the standing rail *UNRESOLVED stays UNRESOLVED* is untouched.

| `identity_lookup` | meaning | evidence about |
|---|---|---|
| `RESOLVED` | registry returned an entity | the symbol |
| `UNRESOLVED` | registry answered, no entity | **the symbol** |
| `LOOKUP_FAILED` | registry could not be read | the lookup, not the symbol |
| `NOT_APPLICABLE` | CASH / PORTFOLIO / MMKT / empty | nothing to resolve |

`stamp_row` keeps the strongest explanation across a row's symbols: a read
failure outranks a clean negative, which outranks "there was nothing to look
up". A row whose registry read failed can never present as cleanly unknown.

Still no mint: every negative path returns `subject_guid: None`.

## 18 — a bare ticker is never a security GUID

Regression locked in three ways: a ticker-only registration keys on
`ticker_alias_guid` (a UUIDv5, 36 chars) and never on the symbol text; the
symbol is recorded in `aliases`; and `by_symbol[SYM]` never maps to `SYM`.
Parameterised over `SCHD`, `12507E201` and `V` so the CUSIP path is covered too.
