## Dry harness (read this before trusting any Wave 2 number)

Several collectors take no `root` and fall back to
`maturity_control.store.resolve_root()`, which is *the checkout the code was
imported from* — and a build worktree has no `data/`. Running a dry measure from
the build worktree therefore silently reports an **empty** book:

| Surface | dry from build worktree | dry with `TRADEAI_ROOT=CURRENT` |
|---|---:|---:|
| `reentry_book.names` | 43 | **70** |
| `watch_block_summary.count` | 0 | **26** |

`scripts/cio_identity_coverage.py` now sets `TRADEAI_ROOT` from `--root`
(default CURRENT) so the harness is correct by construction. Every number below
is the `TRADEAI_ROOT=CURRENT` measurement.

## Slice 13 — % subject_guid on NEW_POSITION_IF / reentry / watch

Two numbers per surface, because one alone lies in a different direction:

* **resolvable** — the identity registry can answer for this symbol today.
* **stamped** — the payload row actually carries `subject_guid`.

```
surface              n    resolvable   stamped   unresolved
new_position_if      5    100.0%       100.0%    []
reentry_book        70    100.0%         0.0%    []
opportunity_book    28    100.0%         0.0%    []
watch_block          8    100.0%         0.0%    []
TOTAL              111    100.0%         4.5%
registry: 10,279 entities / 5,277 symbols
```

**Finding.** There is no identity *gap*: every one of the 111 rows resolves.
What there is, is an identity *carriage* gap — only `NEW_POSITION_IF` stamps the
guid onto the row (`cio_investment_product` calls `stamp_row` there and nowhere
else). Surface A re-entry, the opportunity book and the watch BLOCK list all
resolve and ship nothing.

Reporting a single number would have been misleading either way: "100%" hides
that 106 rows carry no identity, and "4.5%" reads as a registry hole that does
not exist.

Slice 13 says *measure*, so nothing was stamped. Stamping the other three
surfaces is a deliberate follow-on, not a side effect of measuring.

`identity_coverage` is now on the built product (Class D, fail-soft, `minted: 0`).
