## 39 — as_of vs generated_at

```
as_of                    2026-08-26      (position date)
generated_at             2026-08-28 16:45:01 ET
last_repriced            2026-08-28 16:45:01 ET
position_date_age_days   3
reprice_lag_hours        64.8
state                    DATA_STALE
labels                   DATA_STALE · REPRICE_AHEAD_OF_POSITIONS · CASH_TOTAL_DISAGREEMENT
```

**Staleness is measured on the position date, not the reprice date.** A reprice
run 64.8 hours after the positions were built produces fresh-looking prices over
three-day-old positions; measuring freshness on `generated_at` would have called
that OK. An empty document is `DATA_UNAVAILABLE`, never a silent zero.
