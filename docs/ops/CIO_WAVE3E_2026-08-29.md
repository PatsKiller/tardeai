## A test that would have passed vacuously

`test_policy_unavailable_degrades_visibly` blocks the policy import to prove a
missing dependency degrades **visibly** (`available: false`) rather than
rendering an empty, quiet block that looks like "nothing to report".

The first two attempts were wrong. Patching `builtins.__import__` does nothing
because the policy is already imported by the time the test runs; blocking
`sys.modules` alone does nothing because `from scripts.lib import X` resolves
via the package **attribute**. Both versions passed while testing nothing. It
now deletes the attribute as well, and fails if the degradation path breaks.
