# Approved Home v007 additive data contract

`GET /api/v2/market-risk/latest` gains optional `home_v007: HomeMarketRiskContext@v1`. Existing fields keep their contracts. The STOPPED-OUT NOW hotfix (`ReentryRegularQuote@v1` / `PgReader.regular_session_quotes`) ships separately FIRST; this reader extension never changes confirmed stage bars.

- `symbols[SYMBOL]`: `quote`, `day_change`, `since_exit`, `analysis_references`, guarded `headlines`, `next_event`, canonical `cio`, `conviction`, separate `market_risk_stance`, `volume_vs_20d`, `since_exit_history`.
- `positions[]`: existing symbol/account label, observed quote/day change, account-percent denominator, stored-stop distance and captured source. A missing read differs from a successful read with no stored stop. Distances describe existing records; no stop is created, changed or recommended.
- `risk`: existing score history/current delta, all nine canonical category chips, and next declared evaluation. The time comes from the existing DST-safe registry schedule reader; it is explicitly a declaration, not proof that the scheduler is installed or will succeed.
- `hedge`: existing exposure/lagging trigger progress, using the SAME existing Defense values/thresholds and momentum source clock; observed inverse-fund moves, never a suggested position/order.
- `budgets[]`: existing measurement, plain breach/clear condition, and exact `source_binding={as_of,sha256}` over account label/budget/actual/limit/unit/as_of. This binds a future operator-only presentation decision; it grants no authority.
- `gaps[]` and `read_errors[]`: source/field members with stable HOMEV007 remediation keys. No sample values fill a source gap. Raw database diagnostics are not echoed.

Exit-only facts for symbols outside the exited-symbol watch, and CIO facts for inverse quote-comparison rows only, are explicitly `not_applicable`; they do not generate false missing-instrumentation gaps.

Every top-level `symbols[SYMBOL]` fact that is `measured` or `unknown` (including `analysis_references`), each category chip, `hedge.lagging_progress`/`exposure_progress`, `risk.next_evaluation` and `positions[].stop` carries `value`, `state`, `as_of`, `source` and `age_seconds`; when not measured it also carries `reason` and `remediation`. `state` is `measured`, `partial` (only `analysis_references` when some nested references are measured and some are not), `unknown`, or `not_applicable`; `not_applicable` placeholders for exit-only and inverse-display rows carry `value`/`state`/`as_of`/`source`/`reason` but not `age_seconds` or `remediation`. `analysis_references` lists each nested reference's own `state`, `price_as_of` and `reference_as_of`, each unmeasured nested reference is mirrored as a `gaps[]` row whenever the recorded references could be evaluated for the symbol, and an aggregate whose references could not be evaluated at all contributes the single `analysis_references` row. `positions[].stop` carries `price_as_of`, `stop_as_of`, `price_source` and `stop_source`; its own `as_of` is the older of the two clocks and its `source` names both inputs **using only recorded names** — a stored stop that exists with a price and clock but no recorded source is `unknown` with `HOMEV007:positions.stop.provenance` and a gap, never a measured distance resting on an unnamed source. The same-instant conflict rule is judged **only at the instant the displayed quote was selected from**: an older instant's disagreement is not applied to a newer, uncontested observation, and a fact's own `conflict.as_of` always equals its `as_of`. `budgets[]` rows are not five-field facts: they carry `state`, `as_of`, `age_seconds`, `source` and, when `unknown`, `reason`/`remediation`, alongside `actual`/`limit`/`source_binding`. `since_exit_history` is a bounded list of recorded bar observations, not a fact; bars dated after the evaluation session are excluded and reported in `gaps[]`. `next_event` is measured only for a recorded future earnings date; a null or past-dated date is unknown with a reason. Quote facts also carry session/session_date/expected_session_date/basis. A fresh canonical unavailable observation blocks cached old-session substitution; extended prints must belong to the active extended session.

Provenance is never asserted. A value whose source was not recorded carries `source: "not_recorded"` and is `unknown` with a reason and a `gaps[]` row — there is no fallback source string. Headlines are clocked by the newest headline they carry, not by the query that found them: an empty or unguarded news read is `unknown`, never `measured` with age zero. A category chip is affirmative only when its observation is current: the canonical carried-category rule (`market_risk/scoring._carried`) demotes an observation made before a market closure that lies between it and now to `unknown` with `chip: "not_measured"`, `carried: true` and a gap; no threshold or policy value is introduced. Two accepted observations of the **same instant** that disagree are the same fact contradicting itself: the quote is `unknown`, carries `conflict = {reason, as_of, marks[]}`, and one `gaps[]` row names `HOMEV007:quote.conflict`. The rule keys on **distinct prices at that instant**, never on how many rows matched: a duplicate ingest of the same value is not a conflict, and a stored row that agrees with the reader does not hide a second row that differs. A later observation of the same symbol is ordinary movement, not a conflict. `since_exit` carries `price_as_of`, `reference_as_of`, `price_source` and `reference_source`; its own `as_of` is the quote clock (the only input that moves) and its `basis` says the reference is the recorded exit price — an old exit can no longer look as fresh as the quote. `positions[].stop` on the "read succeeded, no record" branch is `unknown` with `observed_status: "not_recorded"`, `stop_as_of: null`, `stop_source: "not_recorded"`, `read_as_of` set to the query clock and a gap — a successful read with no stop is an absence of evidence, never a measured stop. Derived and nested facts are indexed too: `positions[].stop`, `budgets[]`, `risk.categories.*`, `risk.next_evaluation`, `risk.category_changes` and `hedge.*_progress` each contribute a `gaps[]` row while unknown.

A built block carries `state: "available"`. When the additive context cannot be built at all the payload still carries `schema`, `state: "unavailable"`, `generated_at`, `symbols: {}`, `positions: []`, `budgets: []`, `gaps` (one `home_v007` row), `read_errors` (one `home_v007_join` row with a fixed code: `projection_not_evaluated`, `holdings_store_unreadable`, the exception type, or the build-failure type), `reason`, `remediation` and `advisory_only`; **every early return of the join emits it**, so absence of `home_v007` means only that the join did not run at all. A consumer can distinguish unavailable from present-and-empty by `state`, never by presence alone. The block is unconsumed until the Home v007 UI merges; this producer does not ship a consumer.

Day change uses the preceding completed NYSE close; after-hours reference-close movement is never mislabeled the whole day's move. Since-exit/analysis-reference distances use existing exit/stage observations only. Volume compares the observed session volume with twenty PRIOR completed-session volumes; the result states sample dates and that it is not time-adjusted.

CIO stance/conviction uses the existing GUID-confirmed `cio_truth.stances_for_symbols` reader, including store/shadow label, stale flag and oldest material-input age. Deterministic market-risk advice remains separately labeled and never replaces a missing canonical CIO record. The registered stance projection does not expose a current-stance rationale; the UI receives an explicit source gap. Existing score history does not retain earlier category observations, so category-change prose likewise remains explicitly unavailable rather than invented.

Intentional budget decisions must use the existing operator-session + same-origin CSRF route, with explicit UTC expiry, actor/audit receipt and source binding. They are acknowledgment/temporary presentation snooze only: underlying breach truth and an Intentional-until/history record must remain visible. E owns that API implementation; until its reviewed subtype/readback is provided, this contract exposes `operator_decision.state=unavailable` with a remediation, never a fake functional button. No risk limit or policy is changed.

All sources are existing canonical read models/stores. The join creates a bounded read-only connection before its first query, closes it, and performs no broker/provider/model/notification calls or writes. Tests use synthetic prices/accounts/headlines and injected readers; the private portfolio mockup is never opened or committed.

Quote acceptance repair: `expected_session_date` is always selected from the canonical NYSE calendar even when the reader is absent/failing or an entire read falls back to the stored snapshot. Cached metadata cannot choose its own expected session. Valid same-session observations and the last completed session before the open/on closures remain available as dated observations. A rejected/unknown quote supplies no measured day/since-exit/reference-distance/volume derivatives; those facts retain explicit unknown reasons/remediation. Existing frontend last-regular-close context, reader API and stage observations remain unchanged.

Whole-PR provenance repair: a regular quote's independent stored observation clock must fall within the calendar-selected NYSE session, from its open through the fractional closing minute (including early closes). A relabeled prior-session clock, premarket clock, or later after-hours clock cannot become a regular observation. This validates the existing ledger observation clock; it does not claim a provider event time or official close. Before-open/weekend/holiday context remains a dated last-regular-session observation. Category chips use the accepted fact: absent, naive or future source clocks produce `not_measured`, never an affirmative OK/WARN/STRESS chip.
