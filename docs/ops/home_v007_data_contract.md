# Approved Home v007 additive data contract

`GET /api/v2/market-risk/latest` gains optional `home_v007: HomeMarketRiskContext@v1`. Existing fields keep their contracts. The STOPPED-OUT NOW hotfix (`ReentryRegularQuote@v1` / `PgReader.regular_session_quotes`) ships separately FIRST; this reader extension never changes confirmed stage bars.

- `symbols[SYMBOL]`: `quote`, `day_change`, `since_exit`, `analysis_references`, guarded `headlines`, `next_event`, canonical `cio`, `conviction`, separate `market_risk_stance`, `volume_vs_20d`, `since_exit_history`.
- `positions[]`: existing symbol/account label, observed quote/day change, account-percent denominator, stored-stop distance and captured source. A missing read differs from a successful read with no stored stop. Distances describe existing records; no stop is created, changed or recommended.
- `risk`: existing score history/current delta, all nine canonical category chips, and next declared evaluation. The time comes from the existing DST-safe registry schedule reader; it is explicitly a declaration, not proof that the scheduler is installed or will succeed.
- `hedge`: existing exposure/lagging trigger progress, using the SAME existing Defense values/thresholds and momentum source clock; observed inverse-fund moves, never a suggested position/order.
- `budgets[]`: existing measurement, explicit canonical `scope_id` and `breached`, plain breach/clear condition, and exact `source_binding={as_of,sha256}` over canonical scope/budget/actual/limit/unit/breach/source mode/as_of. Display labels are never identity. `presentation_binding` separately binds that observation to the existing operator decision subtype; it grants no risk authority.
- `gaps[]` and `read_errors[]`: source/field members with stable HOMEV007 remediation keys. No sample values fill a source gap. Raw database diagnostics are not echoed.

Exit-only facts for symbols outside the exited-symbol watch, and CIO facts for inverse quote-comparison rows only, are explicitly `not_applicable`; they do not generate false missing-instrumentation gaps.

Every measured fact carries `value`, `state`, `as_of`, `source`, `age_seconds`. Missing/unclocked/future data stays explicitly unknown with `reason` and `remediation`. Quote facts also carry session/session_date/expected_session_date/basis. A fresh canonical unavailable observation blocks cached old-session substitution; extended prints must belong to the active extended session.

Day change uses the preceding completed NYSE close; after-hours reference-close movement is never mislabeled the whole day's move. Since-exit/analysis-reference distances use existing exit/stage observations only. Volume compares the observed session volume with twenty PRIOR completed-session volumes; the result states sample dates and that it is not time-adjusted.

CIO stance/conviction uses the existing GUID-confirmed `cio_truth.stances_for_symbols` reader, including store/shadow label, stale flag and oldest material-input age. Deterministic market-risk advice remains separately labeled and never replaces a missing canonical CIO record. The registered stance projection does not expose a current-stance rationale; the UI receives an explicit source gap. Existing score history does not retain earlier category observations, so category-change prose likewise remains explicitly unavailable rather than invented.

Intentional budget decisions use the existing operator-session + same-origin CSRF `POST /api/v2/governance/budget-presentation/decide` route, subtype `market_risk_budget_presentation`, action `intentional_until`. The body supplies canonical `scope_id`, `budget`, the GET current `source_binding` (the composite `presentation_binding` in Home), an explicit future UTC-Z `intentional_until`, `request_id`, optional `comment` and `dry_run`. It never supplies an actor. `GET /api/v2/governance/budget-presentation?scope_id=...&budget=...` returns the current binding and `budget_presentation_decisions`. Agents/service credentials cannot obtain a basis or decide. The existing approved DecisionLedger records the authenticated actor and hash-chained audit receipt; no second store is created.

The canonical `market_risk_book_join.budget_presentation_snapshot(scope_id=...,budget=...,now=...,root=...)` leaf reuses `market_risk_projection.load_snapshot/build` and the existing assessment budget reader. Schema, mode and evaluation clocks must match; stale/future/missing/duplicate sources fail closed. It performs no Home, database, holdings or ledger hydration, so transaction-time validation cannot recurse into the ledger. Home's `budget_presentation_context(...,ledger=...)` reads the existing ledger and calls pure `with_budget_presentation(...,decision_rows=...,store_approved=...,now=...)`; `None` is unavailable and `[]` is a verified empty read.

Home returns `budget_presentation_decisions` alongside unchanged budget rows. Each budget includes `presentation_binding`, `operator_decision` and its `budget_presentation_decision` (active/expiry/actor/receipt/history). Expiry or any canonical scope/mode/measurement/limit/source-clock change invalidates the intent; the latest expired decision never revives an older one. History remains visible when a breach clears or a source becomes unavailable. An unavailable source GET retains HTTP503, no current basis, and inactive readback history. `operator_decision.state=available` requires a valid current source and approved readable store; otherwise it includes a remediation. These are presentation acknowledgments only: no risk limit, policy, breach, stage, alert or behavior is changed.

All sources are existing canonical read models/stores. The join creates a bounded read-only connection before its first query, closes it, and performs no broker/provider/model/notification calls or writes. Tests use synthetic prices/accounts/headlines and injected readers; the private portfolio mockup is never opened or committed.

Quote acceptance repair: `expected_session_date` is always selected from the canonical NYSE calendar even when the reader is absent/failing or an entire read falls back to the stored snapshot. Cached metadata cannot choose its own expected session. Valid same-session observations and the last completed session before the open/on closures remain available as dated observations. A rejected/unknown quote supplies no measured day/since-exit/reference-distance/volume derivatives; those facts retain explicit unknown reasons/remediation. Existing frontend last-regular-close context, reader API and stage observations remain unchanged.

Whole-PR provenance repair: a regular quote's independent stored observation clock must fall within the calendar-selected NYSE session, from its open through the fractional closing minute (including early closes). A relabeled prior-session clock, premarket clock, or later after-hours clock cannot become a regular observation. This validates the existing ledger observation clock; it does not claim a provider event time or official close. Before-open/weekend/holiday context remains a dated last-regular-session observation. Category chips use the accepted fact: absent, naive or future source clocks produce `not_measured`, never an affirmative OK/WARN/STRESS chip.
