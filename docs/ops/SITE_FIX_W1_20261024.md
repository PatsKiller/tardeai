## Shared read contract

`scripts.lib.cio_truth.resolve(root=None, now=None, *, db_query=None, inputs=None)`
reads existing stores and returns portfolio, positions, stops, regime, approvals,
paper, capital, cio_status, do_now, companies, sectors and conflicts. A named root
contains data/. Normal package execution uses PYTHONPATH=.:scripts, as the existing
Data Broker package requires. No provider, broker, schema-ensure, live send, job,
store initialization or execution-gate call is made by the resolver. No new store.

`stance_for(security_guid, *, db_query=None, now=None, projection=None,
**projection_kwargs)` returns canonical stance, conviction, version, source,
clocks, stale/gap, saved conflict diagnostics and saved C3 review evidence. A
symbol match never substitutes for a GUID. `stances_for_symbols` performs one
prospect read and uses the existing identity_carriage confirmed registry lookup.
It never mints identity. Missing/unconfirmed GUIDs remain explicit gaps.

`security_inputs_for(guid, *, document, projection=None, db_query=None, now=None)`
provides W10 with canonical stance, held context (true/false/unknown), account names
and persisted stop observations. Incomplete GUID coverage never implies not held.

The Conflict Engine is the only classifier. resolve.conflicts forwards an injected
engine envelope unchanged; until W10's accepted projection is integrated it reports
an explicit gap and an empty findings list. Saved record diagnostics are not new
engine flags. W1 adds no rulebook, ledger, decisions or automatic resolution.
C3 REQUESTED/RESEARCHING/ANSWERED_PENDING_CIO do not mean resolved. A saved
CONFLICT_RESOLVED needs the actual C3 readback marker, request, timestamp,
evidence, matching canonical stance and resolved canonical input flags. C3 source
45d57ee843749cfaa6b72e8bf0f1d47dd9afce8e is a dependency, not claimed as merged.

C1 GUID and account labels. Monetary unknowns are null with a reason, not zero.

time. Protection loss means loss to observed active stops only; unprotected downside is
not bounded. Missing DB-backed observations are unknown, even on a valid file copy.
