## Shared interface

`scripts.lib.cio_truth.stance_for(security_guid, *, db_query=None, now=None,
projection=None, **projection_kwargs)` returns `security_guid`, `symbol`, `stance`,
`conviction`, `conflicts`, `revision`, `as_of`, `age_hours`, `stale`, `source`, `gap`.
The optional `projection` is the existing `cio_prospect.get_prospects` response,
allowing a batch reader to load once. Without it the admitted projection is read.
GUID matching is exact; there is no symbol fallback. Missing fields stay null and
carry a reason. Expired evidence stays visibly stale. Conflicts never override
the canonical stance. Returned conflict lists cannot mutate a cached projection.
