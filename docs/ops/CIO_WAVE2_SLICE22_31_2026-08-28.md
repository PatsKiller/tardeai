## 26 — the attach rule, written down so it cannot be tightened by accident

`hermes_research_loop.research_complete_is_attachable` accepts **`VALID` or
`PARTIAL`** (`_SUCCESS_VERDICTS`). Both stamp `hermes_result_id` on the plan.

A `PARTIAL` is usually `no_sources` — the model answered the question but cited
nothing. That is deliberately still attachable: the answer is evidence, its
weakness is recorded in the critique reasons, and dropping it would silently
shrink coverage. Tightening to `VALID` only would drop **74 of 466** currently
attachable results.

Independently of the verdict, a result never attaches when its status is
`failed / error / truncated / cost_cap / cancelled`, when it carries a
`truncated` / `cost_capped` / `failed` flag, or when there is no critique at all.

`attach_rule: "VALID|PARTIAL"` is now stated on the product payload
(`research_quality_counts`) so the rule is visible next to the numbers.
