## Multi-tag contract (required)

| Tag | Producer | When |
|---|---|---|
| `hermes` | Hermes complete | research_result |
| `operator_qa` / `operator_ask` / `operator_deferred` | Desk loop | answered / deferred |
| `thesis` | CIOThesisStore.publish | linked symbols |
| `llm_research` | thesis / LLM lanes | model-authored summaries |
| `lifecycle` | CIO accept | every accepted contribution |
| `backfill` | ops backfill only | historical catch-up (not organic) |

Readers filter by tags; writers **never** fork a private thesis copy.
