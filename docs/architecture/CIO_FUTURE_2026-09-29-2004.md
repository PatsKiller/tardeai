# CIO Persistent Agent — FUTURE (full maturity)

**One-sentence version:** CIO owns one multi-tagged spine tip per `subject_guid`; every advisor/desk path that sees a ticker, sector, or GUID **must** read that tip; a **spine SLA table** + librarian refuse stale answers; operator asks stay active until thesis changes.

LEGEND
  █ LIVE (target) · ◆ new · ★ proven-unattended

---

## Ownership & read contract

| Actor | Duty |
|---|---|
| **CIO** | Owner of spine; accepts contributions; closes operator asks on thesis_publish |
| **Hermes / thesis / LLM lanes** | Writers with tags; never fork private thesis |
| **Advisor agents** (options, holdings, watch, reentry, advisory desk) | **Mandatory** `view_for_silo` / overlay on every resolved subject_guid |
| **Librarian** | Enforce spine SLA before curated answers; queue refresh on breach |

---

## End-to-end (FUTURE)

```
OPERATOR / EVENT
  → resolve subject_guid (+ sector attachments)
  → █★ READ spine (all advisors) + active operator_asks
  → librarian: if spine/thesis older than class SLA → refresh or label STALE
  → answer / research / commit using shared tip only
  → writes: Hermes/thesis/operator tagged contributions
  → thesis_publish ★ closes operator_asks (status=closed_by_thesis)
```
