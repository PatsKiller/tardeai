## Ownership & provenance contract

| Actor | Duty |
|---|---|
| **CIO** | Owner of every spine tip; accepts contributions; closes operator asks on thesis_publish |
| **Hermes** | Writer · tags `hermes` · may upgrade tip thesis when COMPLETE |
| **Thesis publish** | Writer · tags `thesis` · closes `operator_asks` |
| **Operator desk** | Writer · tags `operator_qa` / `operator_ask` · asks persist until thesis |
| **LLM curation / flash** | Writer · tags `llm_research`+`llm_curation`\|`llm_flash`+provider · fills `latest_llm` · **never** tip thesis · **never** fact source · owner remains CIO |
| **Advisor agents** | **Mandatory** `view_for_silo` / overlay on every resolved subject_guid (incl. Aegis overnight) |
| **Librarian** | Enforce spine CLASS_SLA; refuse fresh claims; enqueue Hermes on breach |
