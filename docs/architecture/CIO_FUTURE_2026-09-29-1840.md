## Identity rules (non-negotiable at full maturity)

1. **Mint once** in `IdentityRegistry@v1`; never mint a second map in a silo.
2. **Write-time stamp:** every Hermes req/result, thesis, InstrumentRecord, watch durable row, wake, commitment, spine contribution carries `subject_guid` (and `issuer_guid` when issuer known).
3. **Refuse** SECURITY spine / SDO writes with non-registry GUIDs.
4. **Aliases allowed:** ticker, subject_key, narrative tags — never as the only join.
5. **Research topics** (non-security subjects) use subject_guid with `issuer_guid=NULL` by policy — still unique and persistent.
