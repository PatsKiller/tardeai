## The one missing edge, stated precisely

Every producer writes its durable record, and none writes the SHA it ran under:

```
serving SHA ──► wake ──► receipt ──► commitment ──► AgentView ──► research_object
                    │         │           │             │              │
                    └─────────┴───────────┴─────────────┴──────────────┘
                          all source_sha = "unknown"
```

This is a provenance defect, not a production defect. The fix is a single field
populated at emit time, then asserted by a gate so it can never regress to
`"unknown"`. Until then, "produced on the serving SHA" — the FUTURE bar's exact
wording — is unprovable for any record, however organic.
