## The three gaps that matter most, in order

### 1. Memory loads nothing, and the cliff is why (gaps 4, 5)

Tonight's work made 145 rows findable and then discovered they are all too old
to use: 65 of 71 subjects are past the 168-hour window, median newest-fact age
**432 hours**. The window is a cliff — a fact is either current or invisible.

The fix is not a bigger number. **A 30-day-old observation about a thesis is
not worthless; it is old, and the desk should know that it is old.** Staleness
belongs in the fact as a decay weight the judgment can read, not as a gate that
deletes it. Raising 168h to 720h would move the cliff and change nothing about
its shape.

This is the single highest-value remaining change, because L2, L3 and L4 all
sit on top of memory actually arriving.

### 2. Nothing asks a model (gaps 7, 8)

`provenance.llm` is null on 51 of 51 wakes. Both free OAuth lanes answer
HTTP 200 and the governed bridge is active — **this is not an outage, nothing
calls them.** Meanwhile 24 of 24 AgentViews carry `stance=RECOMMEND`,
`cost_class=zero`, no falsifier, and a fill-in-the-blank summary.

The order matters and it is not "wire a model next". Narration over an empty
context produces fluent text about nothing, which is **worse than the template**
— the template does not sound like it knows something. Memory first, then
judgment.

### 3. The gateway can only ever be staged (gap 11)

Every gateway-SETTLED row in the system's history is a proof message asking the
operator to reply "OK". The transport, settlement and ledger are all correct;
there is simply no advisory producer on that path — 353 of 384 ops messages go
through the legacy send function instead.

**This is why it is BLOCKED, not OPEN.** Manufacturing a fourth proof would
satisfy the counter and prove nothing the first three did not. Closing it means
routing a real producer through the gateway, which changes what reaches the
operator.
