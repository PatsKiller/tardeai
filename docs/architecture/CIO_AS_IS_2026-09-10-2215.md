# CIO AS-IS — every step, every lateral, measured

## LEGEND

### Runtime status

```
█ LIVE        observed at runtime from the served release, unattended, command and output quoted
▓ PARTIAL     runs, but its effect is materially narrower than its name implies
░ UNWIRED     the code is correct and complete; nothing calls it
✗ DARK        no producer, or no consumer, or it has never once executed
◇ BLOCKED     mechanism proven; cannot be exercised without an operator decision
⊘ REFUSED     deliberately not built — an authority rail forbids it
```

### Maturity level reached at that node

```
L1  provenance + liveness    it runs on its schedule and stamps the exact served SHA
L2  grounded                 it reads real prior state about THIS subject before acting
L3  judgment                 a model is asked, validated, and the answer could be wrong
L4  loop closed              the outcome is scored and changes a later question
L5  unattended + self-report it holds without supervision and reports its own decay
```

`L0` means the node exists but has not reached L1.

### Reading the diagram

```
  ══▶   spine        the path one event takes end to end
  ──▶   lateral in   a store or feed READ at this step
  ◀──   lateral out  a durable row WRITTEN at this step
  ╌╌▶   feedback     a later stage changing an earlier one
  ✗✗▶   severed      an edge that exists in the spec and carries nothing today
```
