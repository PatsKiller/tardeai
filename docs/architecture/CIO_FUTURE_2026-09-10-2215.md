## The ordered path from here

Each level is a precondition for the next. **Taking them out of order makes the
system worse, not slower.**

```
  L1 ████████████████████ reached   provenance, liveness, hourly wakes, research
      │
      ▼
  L2 ◆ MEMORY DECAY WEIGHT          the single highest-value change
      │   staleness stops being a cliff. 65 of 71 subjects re-enter.
      │   ⊘ do NOT just raise 168h → that moves the cliff, it does not remove it
      ▼
  L3 ◆ JUDGMENT + CRITIQUE          only AFTER L2
      │   a model over an empty context writes fluent text about nothing,
      │   which is WORSE than the template — the template does not sound
      │   like it knows something
      ▼
  L4 ◆ OUTCOME SETTLEMENT           only AFTER L3
      │   nothing to score until a commitment carries a falsifier
      ▼
  L5 ★ UNATTENDED + SELF-REPORT     all of it, on its own schedule
```

## The one-sentence version

At full maturity the desk raises its own question, answers it from what it
already knows before it spends anything, asks a model only when a material
question survives that, commits to a claim that states what would prove it
wrong, tells the operator once and only when something actually changed, finds
out whether it was right, and gets better — **without ever touching a
position.**

## The count that matters

Not a percentage. AGENTS.md §15 forbids scoring maturity as one. Five proofs,
each observed **unattended, from the served release**:

```
M1 Research     the system raised it, it completed, it changed a named field
M2 Advice       a critique verdict changed the next question — show both
M3 Feedback     an operator reply changed the next wake — show it both ways
M4 Consistency  one producer per number; no two surfaces disagree
M5 Persistence  a disposition made days ago is honoured, with nobody replaying it
```

**A truthful three of five beats a claimed five.** If all five come back
observed on the first attempt, assume something is wrong and find it before
reporting.
