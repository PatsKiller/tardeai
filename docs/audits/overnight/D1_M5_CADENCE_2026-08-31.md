## 1. What #732 already shipped `[CODE]`

Until 2026-08-31, `scripts/lib/cio_rehydrate.apply_after_cycle` set `next_eligible_at` only on:

- rejected / execution-language artifact → +1d
- operator defer honored → +7d (`DEFER_PUSH_DAYS`)

A cadence field that exists only after a failure describes failures, not cadence. Measured that day on the live store: 38/40 records had never carried a value.

#732 added `ROUTINE_LOOK_DAYS = 7` applied **last**, only when `normal_completion and not nxt_at`. Precedence:

```
moved event (due now) > rejection (+1d) > operator defer (+7d)
> the caller's own decision > the routine default
```

7 is not a new number: `cio_residual_web.NEXT_LOOK_DAYS` already uses 7 for a completed hop and 1 for a blocked one. The constant carries that reasoning in source; tests assert the prose remains.

This tranche **did not re-invent** that stamp. It verified it and closed the consult join.

## 2. Cadence skip consult `[CODE]`

`scripts/lib/cio_wake_subject.decide` already returns `skip/cadence_not_due` when the loaded record carries a future `next_eligible_at`. The scheduled wake dispatcher (`cio_wake_dispatch_entrypoint` / `cio_wake_dispatcher`) consults before claim (#723/#724).

This tranche adds an explicit cross-link in `cio_wake_subject.py`: the ordinary writer of the field this consult honours on a normal completion is `apply_after_cycle` → `ROUTINE_LOOK_DAYS`. The consult module does not stamp.

## 5. M5 §15 — NOT OBSERVED on schedule

`AGENTS.md` §15 requires the proof observed **at runtime, from the served release, with the command quoted**. Adjacent machinery exists:

- stamp on normal path (`#732`)
- scheduled consult before claim (`#723` / `#724`)

What is missing for unattended §15 observation: a **scheduled consumer that completes a normal artifact through `apply_after_cycle` (or equivalent stamp) against the live IR store**, so a later scheduled wake finds a future `next_eligible_at` without a human staging the record.

Until that consumer runs unattended and the wake consult artifact (`data/cio/wake_record_consult.json`) shows `skipped_cadence_not_due > 0` from a disposition the normal path wrote, M5 remains **NOT OBSERVED on schedule**.
