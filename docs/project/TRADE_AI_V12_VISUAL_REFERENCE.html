04 — Autonomous Agent Ruleset (Global Rules)

Rule G1
Data Freshness
Never analyze based on data older than: News 7d · Prices 24h · SEC filings 30d · FRED macro 7d. If stale: log event, skip, no recommendation.
if data_age > threshold: skip_analysis()
Rule G2
Income Protection
NEVER recommend TRIM or SELL on any position where yield × market_value > $11,000/yr (20% of $55K target). Strategies: dividend_growth, high_yield_bdc, tactical_income.
if income_contribution > 11000: escalate_to_alex()
Rule G3
SSDI Awareness
Every IRA/401k recommendation must include: MAGI impact estimate · IRMAA flag if MAGI > $103K (MFS) · Bracket flag if MAGI > $94.3K · Medicaid lookback if IRA dist > $50K.
if any_flag: ssdi_review=true, require_human=true
Rule G4
Confidence Gating
No synthesis if own confidence < 40%. No recommendation from single source without corroboration. Expire decisions older than 14 days.
if confidence < 0.40: output LOW_CONFIDENCE_SKIP
Rule G5
Learning Loop
Every analysis must read last 7 outcome lessons from agent_intelligence_rules. Adjust confidence ±0.05 per past approval/rejection from feedback log (last 90d).
inject: "OUTCOME LESSONS — learn from these: [7 lessons]"
Rule G6
Macro Context
Every analysis must include FRED macro context. VIX >25 → hold warning. Inverted curve → recession risk. DFF >5% → bonds competitive. DFF <2% → equity premium.
auto_inject: get_macro_context() → every agent prompt
Rule G7
Escalation Trigger
Auto-escalate to Alex on: agent conflict (BUY vs SELL, 48h) · any Roth conversion · income-critical position · confidence 40-60% on portfolio position.
log agent_handoffs: escalated=true, reason, to_agent='alex'
Rule G9
Debate Requirement
Symbols must pass 3-agent debate (Maria + Steph + Risk) before queuing for Alex. Debate consensus must be ≥50% for any action recommendation.
if consensus < 0.50: status='no_consensus', skip_alex_queue
Rule G10
No Direct Execution
No agent may execute a trade without human approval EXCEPT when: auto_execute rule is enabled=true AND all four conditions met: conf≥90%, ssdi_impact='none', irmaa_risk=false, income_impact='none'. Even then: logged as "auto_approved" — no broker API call. Auto-execute is currently DISABLED by default.
UPDATE agent_intelligence_rules SET config = jsonb_set(config, '{enabled}', 'true') WHERE rule_type = 'auto_execute' AND rule_key = 'low_risk';
