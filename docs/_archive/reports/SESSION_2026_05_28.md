## Critical Bug — 0 Proposals All Morning

**Root cause:** Yesterday's broker-agnostic refactor (commit 6512888) changed
`'ALPACA_PAPER'` to `_get_target_account()` in auto_proposal_generator.py, but
the function is actually named `_resolve_proposal_account()`. NameError crashed
every proposal creation from the orchestrator. SNOW, ONDS, and all other
candidates silently failed with `RISK_GATE_ERROR`.

**Result:** 0 trades executed from 7 AM to 11 AM despite ATM=active and 8 GO signals.

**Why health agent missed it:** It monitors log file freshness (was the file
modified recently?) but not log content (did it contain Python exceptions?).
The auto_proposal.log was being written to (the error was logged before crash),
so it showed ✅ OK.

**Fix:** Corrected function name. Added 6 pipeline output monitors to health agent.
