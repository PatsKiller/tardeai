# Open items — every known gap, with an owner and a review date

```
Status:      ACTIVE
as_of:       2026-10-31
Owner:       coordinator (the register); each row names its own owner
Checked by:  scripts/check_open_items.py (CI: tests/test_governance_open_items_20261027.py)
```

AGENTS.md 26.0.0 holds only current, binding rules. Anything broken, partial, pending, deferred or "named debt" lives
here instead, one row per gap. A rule in AGENTS.md that depends on a gap says what an agent must do **today** and points
here.

**How to use this register**

- **Before you build in an area,** search this file for it. A known gap is not a discovery.
- **When you find a new gap,** add a row in the same PR as your finding: next free `OI-NNN`, a severity, an owner from
  the allowed set, a review date, an action and `open`. `scripts/check_open_items.py` fails a row missing any of them.
- **When you close one,** set `done` and put the PR or commit in the PR column. Never delete a row; the id is permanent.
- **Review dates are proposals** (the coordinator's, 2026-10-27: High in one week, Medium in three, Low in seven). The
  owner may move a date with a one-line reason in the PR. `scripts/check_open_items.py --overdue` lists rows past their
  date.
- **Owners** are lanes, not people: `operator` decides; `coordinator` runs the program; the rest are the agent lanes of
  AGENTS.md §1.
- **This repository is public.** A row names the class of a problem and its remedy, never a secret, a personal value,
  or a map of where personal data sits (AGENTS.md §2A).
